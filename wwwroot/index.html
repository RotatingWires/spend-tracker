Restore a Backup Before Starting

If you have a SpendTracker backup ZIP, restore it before adding entries. Use File > Import/Export... to restore it. Restoring a backup replaces all current data, so anything you add first would be replaced by a later restore. If you don't have a backup, choose Start Fresh.
Import/Export

Download Backup saves a ZIP with every entry, person, payment method, merchant, tag, collection, and the full history. It contains the SQLite database and a backup manifest, but never your password.

Restore a SpendTracker backup ZIP to replace all current data after confirmation. It does not merge. The current data is saved on the server in data/backups first.

Export Transactions CSV downloads every transaction, archived or not, for viewing in a spreadsheet. CSV cannot be imported; use a backup ZIP to restore.
iPhone Shortcut

An iPhone Shortcut can add purchases for you: a Wallet automation each time you pay with Apple Pay, or a Shortcut you run to add one quickly. It saves each entry on the phone first and sends every one not yet saved here, so an entry made away from your network or VPN goes through on a later run. MANUAL.md, under iPhone Shortcut, shows how to build it.

Aliases

Entries from the iPhone Shortcut get this merchant when their merchant name starts with one of these aliases as whole words: BURGER KING matches "BURGER KING #1234" but not "BURGER KINGDOM". Aliases win over another merchant's matching name, and case does not matter.

Fresh Start

Only the selected items will be cleared, then the database is compacted to free disk space. This cannot be undone in SpendTracker. Use File > Import/Export... to download a backup first if you might want to restore them.

Choose what to clear

Removed entries and labels are recorded as Deleted on the History tab, like a normal delete, unless history is cleared too. Entry numbers and IDs are never reused, unless every label is cleared too. Your password and browser preferences are kept.

About SpendTracker

A self-hosted spending tracker. Every number comes from entries you recorded; nothing is guessed or categorized for you.

Record purchases (split between people, or as gifts), refunds linked to the purchase they return, and paybacks from people who owe you. Paybacks never change net spent. Tags, collections, and merchants are labels you add on their tabs; Stats breaks spending down by them.

Tips: click a row to edit it, and use File > Select... to change several at once. File > Import/Export... backs up everything but your password. File > iPhone Shortcut... lets an iPhone add purchases. MANUAL.md has the full guide.
